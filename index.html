ARIA

Accessible Rich Internet Applications (ARIA) provides roles, states, and properties that help assistive technologies understand custom web components when native HTML is not enough. Use semantic HTML whenever possible and ARIA only when needed. Learn more about ARIA and how to use it in the following resources:

  • WAI-ARIA specification
  • ARIA Authoring Practices Guide (APG)
  • MDN ARIA documentation

Best practices

Your counselor Coder Bear has curated this list of best practices to guide you as you work through the exercises. Take a new trail and explore.

Semantic HTML first
Use native HTML when well supported by browsers and assistive technologies; use ARIA only when needed.
No ARIA is better than bad ARIA
Follow the ARIA Authoring Practices Guide (APG) carefully when implementing ARIA patterns.
Avoid "div soup"
Use semantic HTML elements and ARIA roles to convey meaning and structure, rather than relying on generic <div> elements.
